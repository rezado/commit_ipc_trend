01 / OVERVIEW

整体性能

先看发布分数与运行条件，再决定深入哪些 workload。

02 / WORKLOADS

Workload 排查

按 CPI 变化排序；完整切片集计算加权 CPI，部分覆盖仅作诊断。

03 / SLICES

关键切片

按权重 × ΔCPI 排序；正值是退化贡献，负值是抵消改善。

04 / COUNTERS

性能计数器

对同一切片、同一语义版本与统计窗口的 A/B 数值配对。

PERF 计数器来自末次 dump；切片 CPI 来自 ROI 汇总。两者窗口可能不同，计数变化只用于定位，不直接证明因果。
